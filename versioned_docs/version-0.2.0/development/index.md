# Development

These pages are for contributors changing remoteexec itself. Operators should
start with the [documentation index](../index.md).

- [Development setup](setup.md) covers the Go toolchain, validation gate,
  Windows fixtures, and the locally recorded terminal demo.
- [Releasing](releasing.md) defines the branch, tag, and artifact checks for a
  release.
- [Architecture](../architecture.md) describes the registry, execution engine,
  platform backends, delivery adapters, and result contract.

Repository-wide working rules are in
[`AGENTS.md`](https://github.com/rubyattack3r/remoteexec/blob/v0.2.0/AGENTS.md).
